# 一站式题库助手

一个使用 Python 开发的开源项目

## 功能特点

- 项目源码结构清晰，便于阅读、修改和二次开发
- 主要技术栈：Python
- 支持通过 Git 进行版本管理和协作

> 请根据项目实际情况补充更具体的业务功能。

## 环境要求

- Git
- 与项目技术栈匹配的运行环境：Python

## 安装与运行

克隆仓库：

```bash
git clone https://github.com/<你的账号>/一站式题库助手.git
cd 一站式题库助手
```

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```powershell
python main.py
```
