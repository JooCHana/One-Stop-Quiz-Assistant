# 一站式题库助手 1.0.1

Windows 三合一桌面软件。双击“一站式题库助手.exe”即可使用，无需安装 Python，也不依赖原来的三个程序目录。图片识别在本机离线完成。

## 独立使用

不勾选“接力运行”，点击所需功能卡片，设置参数后点击“开始”。

### 截图翻页

1. 打开题目页面，框选截图区域。
2. 设置截图数量、起始编号和步骤延时。
3. 选择点击下一题并设置按钮位置，或设置拖动翻页手势。
4. 点击开始，程序最小化，3 秒后开始截图。

默认直接截取屏幕区域。也可选择“系统截图”，使用 Win+Shift+S；等待时间在设置中调整。每次任务创建独立文件夹，最后一张截图后不再翻页。请保持题目窗口位置不变。

### 截图识别

1. 选择图片或截图文件夹。
2. 开始识别，可在“图片预览”查看截图，在“题目结果”查看结果。
3. 完成后自动生成 Word、Excel 和 JSON。
4. 需要修改时，在题目结果中双击编辑，再点击“导出题库”保存。

蓝色勾选直接作为正确答案。未检测到答案时保持空白，避免编造答案。失败图片及原因记录在任务目录；成功识别的题目仍会导出。

### 自动答题

1. 选择题库后自动导入。题库文件下方显示“已导入 N 道题”，并自动打开“题库预览”，可查看题干、选项和正确答案；需要重新读取时点击“重新导入”。
2. 刷新并选择目标窗口。
3. 选择下一题方式，设置最低匹配度及步骤延时。
4. 可先点击“仅识别测试”，检查题目匹配结果，此操作不会点击答案。
5. 点击“开始答题”后自动答题。导入结束或失败后开始按钮都会恢复；缺少参数时会显示具体提示。匹配不足、选项无法定位或翻页不成功时停止并记录原因。

支持 .xls、.xlsx、.xlsm、.csv、.tsv、.doc、.docx、.txt。Excel 兼容“题干 / 选择项1—4 / 答案1”格式，也支持“试题内容 / A—H / 正确选项”等原有表头。“答案1”为正确答案，“答案2”不覆盖正确答案。没有正确答案和选项的行不会用于自动答题。

答题时使用所选窗口的完整区域；公共“截图区域”用于截图翻页模块。

## 接力运行

1. 在截图卡片设置区域、截图数量和翻页方式。
2. 在答题卡片选择目标窗口和切题方式；无需预先选择题库。
3. 勾选“接力运行”，点击“开始接力”。
4. 程序自动截图、识别、导出题库，并把生成的 Excel 交给答题模块。
5. 默认在建库完成后等待。请自行切到需要答题的起始页，然后按“继续答题”或暂停/继续热键。

如果页面已安排好自动切换，可在设置中关闭“等待我切到答题起始页”，改用倒计时接力。程序不会自动返回第一页或重新打开考试；倒计时结束时，目标窗口必须已显示可答题页面。

如有识别失败或缺少答案，接力停止，保留已生成题库；校对、补充并导出后可独立启动自动答题。

## 界面与快捷键

- F8：开始；F9：暂停/继续；Esc：停止。可在设置中调整，三个热键不能重复。
- 暂停和停止在当前单次 OCR 或鼠标动作结束后生效；自动答题时 Esc 始终可紧急停止。
- 暂停会显示工作台；恢复截图或答题时再次最小化，避免遮挡目标页面。
- “打开目录”打开最近任务输出；每次任务都有独立的截图和题库子目录。
- 日志可清空或导出；拖动日志与参数之间的分隔条可调整布局。
- 支持浅色、深色、置顶、缩放；关闭时保存窗口布局、主题和参数。
- 设置位于 `%APPDATA%\一站式题库助手\settings.json`，不修改原三个程序的设置。
- 截图和答题过程中请保持目标页面完整可见，避免移动鼠标或调整窗口。

## 验证范围

已用指定的 40 题 Excel 和示例截图验证导入、识别、导出再导入及题目匹配；对截图数量、翻页次数、暂停停止、接力等待进行了模拟测试。未在用户的实际答题页面上执行自动点击。
